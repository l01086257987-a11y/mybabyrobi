# 우리의 첫 장면

생일 선물용 웹사이트예요. 영화 티켓 모양 입장 화면에서 **처음 사귄 날짜**를 맞혀야 열립니다.

화면은 이 순서로 이어져요: 입장 → 꽃 오프닝 → S#1 첫 만남 영상 → S#2 함께한 날들 → S#3 편지 → S#4 케이크 → 광장 게임(선물·쿠폰) → 엔딩 크레딧

편지, 사진, 영상은 입장 날짜를 비밀번호로 써서 **암호화한 상태로** 올라가요. 그래서 공개 저장소에 올려도 GitHub에서 내용을 볼 수 없어요.

## 폴더 구조

```
index.html          화면 뼈대
assets/             디자인(style.css), 동작(app.js), 광장 게임(game.js), 3D·중계 라이브러리(vendor/)
data/               암호화된 내용  ← 깃허브에 올라감
private/            원본 편지·사진·영상  ← 깃허브에 안 올라감 (.gitignore)
  content.json      모든 글과 날짜
  media/            사진, 영상, 음악 원본
tools/encrypt.mjs   private → data 로 암호화
tools/decrypt.mjs   data → private 로 복구
```

## 내용 바꾸기

1. `private/content.json`에서 글과 날짜를 고쳐요.
   - `password`: 입장 비밀번호로 쓸 날짜
   - `together.firstDay`: 사귄 날을 0일로 세면 `0`, 1일로 세면 `1`
   - `together.birthdayNote`: 생일 당일에만 D+ 아래에 뜨는 한 줄
   - `question`: 입장 화면 질문 (예: "우리가 처음 사귄 날은?")
   - `hint`: 두 번 틀리면 보여줄 힌트
   - `question`과 `hint`는 입장 전에 보여야 해서 암호화되지 않아요.
2. 사진과 영상은 `private/media/`에 넣고, content.json에는 `"media/파일이름.jpg"` 형식으로 적어요.
3. 아래 명령으로 암호화해요. Node 18 이상이 필요해요.

```bash
node tools/encrypt.mjs
```

음악을 넣으려면 `"music": "media/song.mp3"`처럼 적으면 돼요. 그러면 오른쪽 위에 음악 버튼이 생겨요.

## 선물 상자 문제 (`gift.questions`)

케이크 촛불을 끄면 자물쇠 걸린 선물상자가 나와요. 문제를 다 맞히면 열리면서 `gift.coupon`이 나와요.

```json
{ "q": "보기 중에 고르는 문제", "choices": ["가", "나", "다"], "answer": "나", "hint": "틀리면 보여줄 힌트" }
{ "q": "직접 적는 문제", "answers": ["정답", "다른 정답"], "hint": "B로 시작해" }
```

직접 적는 문제는 띄어쓰기, 대소문자, 문장부호를 무시하고 채점해요.

## 광장 게임 (케이크 다음)

케이크 촛불을 끄면 **게임 입장** 버튼이 나와요. 눈 내리는 밤 광장에서 Beomjun이 들고 있는 선물을 Robi에게 건네고, Robi가 자물쇠 문제를 풀면 쿠폰이 나와요.

- **각자 폰으로**: Robi는 평소 주소로, Beomjun은 주소 끝에 `#beomjun`을 붙여서 들어가요. 둘이 동시에 접속해 있어야 서로 보여요. 가입 없이 쓰는 공개 무료 중계 서버 두 곳(HiveMQ, EMQX)으로 위치만 주고받아요.
- **한 폰으로**: 오른쪽 위 버튼을 누르면 왼쪽 조이스틱은 Beomjun, 오른쪽은 Robi를 움직여요. 중계 서버 연결이 안 될 때도 이 모드로 할 수 있어요.
- **안아주기 · 볼 뽀뽀**: 두 캐릭터가 가까워지면 오른쪽에 🤗 💋 버튼이 생겨요. 누가 눌러도 되고, 각자 폰이면 두 화면에서 같이 나와요. 볼 뽀뽀는 누른 사람이 상대 볼에 해요 (한 폰 모드에서는 Beomjun → Robi).
- **채팅**: 각자 폰 모드에서 오른쪽 아래 말풍선 버튼으로 메시지를 보내면 캐릭터 머리 위에 말풍선이 떠요. 메시지는 입장 날짜로 암호화해서 보내서 중계 서버에서는 읽을 수 없어요.
- 새로고침하면 선물 상태가 처음으로 돌아가요. 미리 테스트했다면 실제로 할 때 둘 다 새로고침하고 시작하세요.
- 방 번호(`game.room`)는 암호화된 내용 안에 있어서 두 사람만 같은 광장에 들어와요.

## 미리보기

파일을 더블클릭해서 열면 동작하지 않아요. 간단한 서버를 띄워서 열어 주세요.

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 http://localhost:8000 을 열면 돼요.

## 깃허브에 올리기

1. GitHub에서 새 저장소를 만들어요. 저장소 이름이 주소가 돼요 (예: `아이디.github.io/our-first-scene`).
2. 이 폴더 전체를 올려요. `private/`는 자동으로 빠져요.
3. 저장소 **Settings → Pages → Branch: `main` / `(root)`** 를 선택하고 저장해요.
4. 1~2분 뒤 위 주소로 접속돼요.

**`private/` 폴더는 깃허브에 안 올라가요.** 그러니 원본은 내 컴퓨터에 따로 꼭 보관해 주세요.

## 영상 팁

- mp4(H.264) 형식이 아이폰, 안드로이드, 카카오톡 브라우저에서 가장 잘 나와요.
- 휴대폰에서 빨리 뜨게 하려면 40MB 이하를 권장해요. 줄이는 방법:

```bash
ffmpeg -i 원본.mp4 -c:v libx264 -crf 24 -preset slow -vf "scale='min(1280,iw)':-2" -c:a aac -b:a 128k -movflags +faststart private/media/first-meet.mp4
```

## 원본을 잃어버렸을 때

깃허브에 올라간 암호 파일에서 원본을 되살릴 수 있어요. 입장 날짜만 알면 돼요.

```bash
node tools/decrypt.mjs 2024.03.12
```
